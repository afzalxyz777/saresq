The array is read as two interleaved subpages. A read straddling a refresh mixes two moments, inflating apparent contrast — so it is discarded before it can reach the gate.

FIND CANDIDATES

CONTRAST-RELATIVE THERMAL GATE

Every pixel scored against the scene itself, never against a fixed temperature:

z = (T − scene median) / σ
TWO-SIDED TEST · |z| ≥ 2.5

Fires on deviation in either direction. Above ~35 °C ambient a body is cooler than sun-heated ground, where a “warmer than background” test goes blind.

ROI SELECTION

Connected regions ranked by z; up to six 160 × 160 crops passed on. Everything else is discarded without ever reaching a neural network.
