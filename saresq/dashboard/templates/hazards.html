What this classifier can call

Trained classes — collapsed building, fire, flooded area, traffic incident, normal.

Precipitation is not one of them. There is no rain class in the training data, so the system will never claim to see rain. What it does detect is flooding — the consequence that matters for tasking a rescue — and it reports the real ambient temperature above from the thermal array.

A scene the classifier calls normal is an answer, not a gap: it means all four hazard classes were evaluated and scored low.
